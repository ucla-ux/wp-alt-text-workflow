# alt-prompt

For one image at a time. For a whole Media Library, use alt-find, alt-generate and alt-import.

## Steps

1. If the user did not say where the image appears, who the site is for, or who is in it, ask in one message. Do not name anyone yourself.
2. Write the alt text using the prompt in `README.md` in this skill's folder as the rules: one sentence, under 150 characters, American spelling, no "image of", say what a reader gets from the image on that page.
3. Reply with the alt text and one line on anything to check.

## Rules that do not bend

- Never describe a person's appearance or guess their gender, race, ethnicity, disability, religion or nationality. Never identify anyone from their face. A name comes only from what the user told you.
- Chart, map or infographic: give a one-line summary and say a person needs to write a longer description.
- If you cannot tell what the image shows, say so.
